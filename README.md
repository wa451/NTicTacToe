# 変則N目並べ（Variable N-in-a-Row）

10×10の盤面上で、ターン毎に変化する勝利条件とウィンドウに対応しながら戦う、運と戦略を組み合わせたWebゲームです。

## 🎮 ゲームの特徴

### 動的な勝利条件
毎ラウンド、目標の連続数（3〜10個）がランダムに決まります。常に変化する目標に対応する必要があります。

### ウィンドウシステム
盤面の一部のみが有効エリア（ウィンドウ）として指定され、明るく表示されます。ウィンドウ内のみ石を置くことができ、毎ラウンド位置とサイズが変化します。

### AI対戦
2つの難易度で楽しめるAI対戦機能を搭載：
- **EASY**: 勝ち/負け防止アルゴリズム
- **NORMAL**: 評価関数ベース（デフォルト）

## 🎯 ルール

1. **プレイヤー**: プレイヤー1（黒）vs AI（白）
2. **目標**: ウィンドウ内で、縦・横・斜めのいずれかに目標数の石を並べる
3. **ターン**: 両プレイヤーが1手ずつ打つと次のラウンドへ
4. **新ラウンド**: 目標数とウィンドウ位置がランダムに再設定される
5. **勝利**: 目標数を先に並べたプレイヤーが勝利

## 🚀 技術スタック

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **AI**: カスタム実装（評価関数ベース）

## 🎲 遊び方

1. **ゲーム開始**: 自動的に目標数とウィンドウが決定されます
2. **手を打つ**: 明るく表示されたエリア（ウィンドウ）内の空きマスをクリック
3. **AIのターン**: 0.8秒後にAIが自動で手を打ちます
4. **難易度変更**: いつでもEASY/NORMALを切り替え可能
5. **リセット**: 「ゲームをリセット」ボタンで新しいゲームを開始

### スマホでの操作
- タイトル横の「?」アイコンでルール説明を表示
- 盤面の上に目標数と現在の手番が表示されます

## 🤖 AI難易度の詳細

### EASY（勝ち/負け防止）⭐⭐⭐☆☆
**アルゴリズム**:
1. 自分が勝てる手があるか探す → 勝つ
2. 相手が次に勝てる手を防ぐ
3. どちらでもなければランダム

**特徴**: シンプルだが効果的な防御

### NORMAL（評価関数ベース）⭐⭐⭐⭐☆
**アルゴリズム**:
各空きマスにスコアを付けて最適な手を選択

**スコアリング**:
- 自分のN連完成（勝利）: +10,000
- 自分のN-1連（リーチ）: +500
- 自分のN-2連: +100
- 相手のN-1連を防ぐ: +400
- 相手のN-2連を防ぐ: +80
- 中央寄りボーナス: +20

**特徴**: 攻撃と防御のバランス、先読み能力あり

## 🎨 レスポンシブデザイン

### デスクトップ
- 左サイドバーに情報パネルとAI難易度選択
- 中央に大きな盤面
- 勝利時は画面上部に小さなモーダル

### スマホ
- 盤面の上に情報を集約表示
- 目標と手番を横並びに配置
- 勝利時は画面最上部に横長のモーダル（盤面を遮らない）

## 🔧 カスタマイズ
